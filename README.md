## Open data

Every list on the site is also a CSV file in [`/data`](data/), so you can use it in your own app, flashcard deck, or classroom.

| File | Rows | Columns |
|---|---|---|
| [`spanish-flashcards.csv`](data/spanish-flashcards.csv) | 300 | rank, spanish, english, part_of_speech, example_es, example_en, deck |
| [`spanish-flashcards-anki.txt`](data/spanish-flashcards-anki.txt) | 300 | Anki import file (tab-separated, with tags) |
| [`100-easy-spanish-words.csv`](data/100-easy-spanish-words.csv) | 100 | spanish, english, pronunciation, topic, example_es, example_en |

## About Parrot

[Parrot](https://www.parrotapp.com/?utm_source=github&utm_medium=referral&utm_campaign=free_resources&utm_content=readme-about) teaches Spanish with short videos from native speakers, matched to your level. Tap any word to see what it means and save it as a flashcard. Parrot is free to start on [iPhone](https://apps.apple.com/us/app/parrot-learn-spanish-language/id6736955121), [Android](https://play.google.com/store/apps/details?id=com.fluentwithparrot), and the web.

Parrot is backed by [Y Combinator (F25)](https://www.ycombinator.com/companies/parrot) and used by 700,000+ learners. Before we wrote any code, we used 52 language apps and interviewed 65 learners. [Read our story](https://parrot-learning-inc.github.io/about/).

Made by [Amir Hanna](https://www.parrotapp.com/blog/author/amir-hanna) (CEO), [Erik Dahl](https://www.parrotapp.com/blog/author/erik-dahl) (CTO), and [Julia Hudea](https://www.parrotapp.com/blog/author/julia-hudea) (CPO), with the [Parrot team](https://www.parrotapp.com/team).
